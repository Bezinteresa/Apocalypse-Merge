## Архив

- `apocalypse-merge-0.4.0-yandex.zip`: 160 файлов, 11,4 МБ в распакованном виде (лимит 100 МБ), `index.html` в корне, пути через `/`, без пробелов и кириллицы.
- Пути относительные (Vite `base: './'`), Bridge лежит в архиве (`playgama-bridge.js`), CDN не используется.
- Внешние адреса в собранных файлах есть только в `playgama-bridge.js` — это адаптеры других площадок внутри Bridge; на Яндексе они не вызываются. В коде игры (`assets/*.js`, `*.css`) внешних адресов нет, поэтому CSP в консоли настраивать не нужно.
- В сборку вошла текущая графика из рабочей папки, включая ещё не закоммиченные картинки ChatGPT (`ui/cell_locked.png`, `zones/R14_*`, `zones/R18_fixed.png`). Перед загрузкой можно пересобрать архив после их коммита — команды ниже.

```powershell
npm run build
$stage = "$env:TEMP\am_yandex"; Remove-Item -Recurse -Force $stage -ErrorAction SilentlyContinue; Copy-Item -Recurse dist $stage
Remove-Item "$stage\sprites\ui\cell.png" -ErrorAction SilentlyContinue
Push-Location $stage; & "$env:SystemRoot\System32\tar.exe" -a -c -f "H:\Html AI\ApoclypseMerge\Store\yandex\apocalypse-merge-0.4.0-yandex.zip" *; Pop-Location
python Store/yandex/check_zip.py Store/yandex/apocalypse-merge-0.4.0-yandex.zip
```

Apocalypse Merge — мердж-2 без монетизации покупками: внутриигровых покупок и платного контента в игре нет.

Звук — короткие синтезированные эффекты, переключатель в настройках (⚙); там же сброс прогресса. Музыки нет.

## Видео (делает владелец)

Нужно горизонтальное 16:9 (обязательно) и, по желанию, вертикальное 9:16: MP4, высота от 400 px, до 28 с, до 100 МБ, игровой процесс не меньше 70% времени, без системного интерфейса. Первые 3 секунды — самое живое: цепочка объединений и сдача заказа, затем ремонт в магазине с окном итога и открытие сундука.

1. Запустите игру: `npm run preview -- --port 4173 --strictPort`, откройте `http://localhost:4173/` в Chrome, нажмите F11 (полный экран, без адресной строки). Кнопку DBG перед записью лучше скрыть: F12 → Console → `document.querySelector('.debug-btn').hidden = true`.
2. Запись: Win+G (Xbox Game Bar) → «Записать» (Win+Alt+R начать/остановить; файлы в `Видео\Captures`) или OBS (источник «Захват окна», выход 1920×1080, 30 или 60 к/с).
3. Для вертикального видео в Chrome: F12 → значок телефона (Ctrl+Shift+M) → размер 540×960 и запись области окна в OBS, либо вырезать центр из горизонтальной записи (ниже).
4. Обрезка и сжатие ffmpeg (установить: `winget install Gyan.FFmpeg`):

```bash
ffmpeg -ss 5 -t 27 -i raw.mp4 -vf "scale=-2:1080,crop=1920:1080" -c:v libx264 -crf 23 -preset slow -pix_fmt yuv420p -an Store/yandex/gameplay_16x9.mp4
```

```bash
ffmpeg -ss 5 -t 27 -i raw_vertical.mp4 -vf "scale=1080:-2,crop=1080:1920" -c:v libx264 -crf 23 -preset slow -pix_fmt yuv420p -an Store/yandex/gameplay_9x16.mp4
```

`-ss` — с какой секунды начать, `-t 27` — длительность (меньше лимита 28 с). Если файл больше 100 МБ, увеличьте `-crf` до 26–28.

## Что сделать в консоли владельцу

1. Создать черновик, загрузить `apocalypse-merge-0.4.0-yandex.zip` (Общее → Архив) и заполнить поля «Общее» из таблицы выше.
2. Включить облачные сохранения.
3. В «Описание и продвижение» для русского и английского вставить тексты, загрузить иконку, обложку своего языка, витрину своего языка и скриншоты своего языка.
4. Записать и загрузить горизонтальное видео (вертикальное — по желанию).
5. Проверить игру на черновике по пункту чек-листа выше и сообщить ID игры — его стоит записать в `docs/PLAYGAMA_STATUS.md`.
6. Если Яндекс выдаст ID рекламных блоков — их можно прописать для placements `energy_bonus` и `project_completed` в `public/playgama-bridge-config.json`.
