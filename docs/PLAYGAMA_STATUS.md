# Интеграция Playgama Bridge — текущее состояние

Обновлено: 22 октября 2026 года (реклама подключена). Полное техническое задание — [PLAYGAMA_INTEGRATION_PROMPT_RU.md](PLAYGAMA_INTEGRATION_PROMPT_RU.md). Здесь отмечается, что из него уже реализовано и проверено.

## Стек

| Что | Выбор | Почему |
| --- | --- | --- |
| Язык | TypeScript 5.9 | Типы для правил, контента и сохранений |
| Сборка | Vite 7.3.7, `base: './'` | Плагин Bridge для Vite, архив работает из подкаталога |
| Отображение | DOM + CSS Grid, без фреймворка | Поле 7 × 9 и панели — это интерфейс, а не 3D-сцена; Three.js и Vue на этом объёме не нужны. Pixi/Canvas можно добавить на визуальном этапе, правила от этого не меняются |
| Тесты | Vitest | Правила мерджа и сервис сохранений проверяются без браузера |
| SDK | `@playgama/bridge` 2.3.1 (зафиксирована точно) | Версия из контрольного примера ТЗ, последняя в npm на дату подключения |

Bridge подключается плагином `playgamaBridge({ mode: 'local' })`: в сборку кладётся `playgama-bridge.js`, тег стоит первым в `<head>`, CDN Bridge не используется. Код игры импортирует `bridge` из `@playgama/bridge` (обёртка над `window.bridge`). Конфиг — `public/playgama-bridge-config.json`, Vite копирует его рядом с `index.html`.

## Реклама (подключена 22.10.2026)

Параметры предложены в ТЗ и утверждены пользователем; это баланс проекта, а не требование площадки.

| Формат | Где и когда | Правила | Код |
| --- | --- | --- | --- |
| Rewarded `energy_bonus` | Окно энергии (нажатие на счётчик ⚡); предлагается само при попытке выдачи без энергии | Кнопка «Смотреть рекламу: +20 ⚡». Награда только по состоянию `rewarded`, ровно один раз; отмена, ошибка, исключение SDK и отсутствие рекламы ничего не дают и попытку не расходуют. Лимит 3 успешных награды, затем 3 часа; хранится в сохранении (облако), переживает перезагрузку | `src/game/ads.ts`, `src/platform/ads.ts`, `src/ui/gameScreen.ts` |
| Interstitial `project_completed` | После закрытия окна итога ремонта, начиная с R02 (не в обучении) | Первый запрос не раньше 180 с после запуска, затем не чаще раза в 7 минут — решение пользователя от 24.10.2026, было 120 с (в игре и в конфиге Bridge: `initialInterstitialDelay` 180, `minimumDelayBetweenInterstitial` 420). Итог ремонта сохранён до запроса; после `closed`/`failed`/тайм-аута игра продолжается один раз, сцена с персонажем ждёт закрытия рекламы | там же |
| Sticky-баннер | Не подключён | В предложенный набор не входил | — |

Общий сервис `AdService`: один запрос в работе (повторные нажатия и параллельная межстраничная блокируются), пауза игры причиной `ad` от запроса до закрытия, тайм-аут 15 с без открытия и 120 с открытой рекламы, поздние события старого запроса игнорируются, запоздавшее `rewarded` сразу после `closed` принимается (порядок событий адаптера Яндекса 2.3.1: `opened → rewarded → closed`, проверен по коду пакета).

Проверка: 9 тестов сервиса и правил (успех, отмена, ошибка, исключение, поздние события, параллельные запросы, тайм-ауты, лимит и перезарядка после перезагрузки, расписание). В игре — через локальную имитацию `http://localhost:5173/?fakeads=1` (`?fakeads=cancel` — отменённый просмотр; работает только на localhost): награда, пауза, лимит 3 и перезарядка 3:00:00, отмена без награды, межстраничная после R02 и её отсутствие после R01. **На площадке не проверено:** QA Tool Playgama во встроенном браузере не загрузил localhost (блокировка браузера); проверить в обычном Chrome по ссылке из `get_local_game_qa_tool_link` или на черновике Яндекса.

Ограничение: время перезарядки берётся с устройства — перевод часов её обходит; серверное время подключим перед публикацией вместе с энергией.

## Ещё не сделано

- **Sticky-баннер, IAP, лидерборд** — вне объёма прототипа (PROTOTYPE_PLAN, раздел 5).
- **Аналитика** — вехи игры отправляются через `bridge.analytics.send` (чек-лист Playgama, п. 19); внешней аналитики нет.
- **Звук** (24.10.2026): простые синтезированные эффекты через Web Audio (`src/platform/sound.ts`, без звуковых файлов): выбор, выдача предмета, объединение (выше уровень — выше тон), ошибка, сдача заказа, ремонт, расчистка, сундук и карты. Молчат при любой причине паузы (реклама, фон, потеря фокуса) и при запрете звука площадкой (`audioAllowed`); переключатель «Звук» в настройках сохраняется (сохранение v13, сброс прогресса его не меняет). Музыки нет.
- **Облачные сохранения Яндекса** — Bridge сам выбирает хранилище; поведение на Яндексе не проверено.
- **Проверка на площадке** — ID игры Яндекса и черновика нет. Всё выше проверено только локально в режиме `mock`. **Не проверено на платформе.**
- **ZIP релиза** собирается вручную из `dist/` в `release/` (папка в `.gitignore`); архив для песочницы — выше.
- **Время для энергии** берётся с устройства. Перевод часов вперёд ускоряет восстановление; серверное время (`platform.getServerTime`) подключим перед публикацией, если энергия останется в игре.
- **Отладочная панель** (DBG) показывается только при запуске на `localhost`; перед релизом проверить, что в сборке на площадке её нет.
