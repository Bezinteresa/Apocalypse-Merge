# Графика через ChatGPT — конвейер

Версия 2 · 22 октября 2026 года. Изображения генерирует пользователь в ChatGPT; агент ведёт спецификацию, пишет промты, сохраняет, сжимает, проверяет и подключает файлы. Порядок перенесён из проекта «Победа над чудовищем» и адаптирован к рисованному стилю этой игры.

## 1. Принципы

- **Игра не ждёт графику.** У каждой сущности есть заглушка — цветная плашка с подписью и номером уровня. Нет файла — заглушка, файл появился — картинка. Код править не нужно.
- **Имя файла — адрес слота:** `public/sprites/<категория>/<id>.<png|webp>`, например `items/T01.png`, `generators/G_TOOL.png`, `portraits/LEV.png`, `shop/shop_R03.webp`, `cards/C_RADIO.webp`.
- **Один файл — одна картинка.** Без коллажей, рамок, подписей и водяных знаков.
- **Спецификация — единственный источник правды:** [art/generation-prompts.json](../art/generation-prompts.json). Новая сущность в данных = новая строка в спецификации в том же изменении; тест `src/content/art.test.ts` падает, если слота нет.
- **Генерируем только недостающее:** перед каждой сессией `node art/art_todo.mjs` строит [art/ART_TODO.md](../art/ART_TODO.md).

## 2. Как сгенерировать очередную партию

1. `node art/art_todo.mjs` — свежий список «что сгенерировать сейчас».
2. В ChatGPT: отдельный чат на группу (предметы, генераторы, портреты, магазин, коллекция). Первым сообщением — блок стиля из раздела 3, затем по одной картинке из `ART_TODO.md`: `subject` + строка «Кадр».
3. Первую удачную картинку сохраните как `art/reference/style.png` и прикладывайте к каждой следующей генерации: `Match the exact art style, line weight, lighting and colors of the attached image.`
4. Уровни одной цепочки делайте подряд и прикладывайте предыдущий: `Same item family as the attached image, next upgrade level.` Так рост уровня читается силуэтом.
5. Сцены магазина — правками одной картинки: у каждого шага в списке указано «Приложи как основу для правки». Ракурс и расположение не должны меняться.
6. Сохранить в игру (уменьшение со сглаживанием, без случайной перезаписи):
   ```bash
   python art/save_generated_asset.py <скачанный_файл> items/T01.png 256 256 --trim
   ```
   `--trim` срезает прозрачные поля и центрирует объект — полезно для предметов, генераторов и сундуков. Для переделки добавьте `--replace`. Файлы `.webp` (магазин, карты) сохраняются непрозрачными с обрезкой под пропорции.
7. Сжать тяжёлые PNG (оригиналы — в `art/originals/`):
   ```bash
   python art/compress_sprites.py
   ```
8. Проверить всё разом — размеры, прозрачность, контактные листы в `art/generated-previews/`, в том числе `items-48px.jpg` (предметы в размере клетки на телефоне):
   ```bash
   python art/verify_generated_assets.py
   ```
9. Снова `node art/art_todo.mjs` — сделанное пропадёт из списка. В режиме `npm run dev` игра перезагрузится и покажет новую картинку сама.

Неудачную картинку не удаляйте: поставьте ей в спецификации `"redo": "что не так"` — она вернётся в список с причиной.

## 3. Блок стиля — первым сообщением в каждом чате

```text
You are making game art for "Apocalypse Merge", a cozy post-apocalyptic merge-2 mobile game about restoring a small shop at a city crossroads.

Art style rules for every image in this chat:
- Hand-painted 2D cartoon style, clean bold outlines, soft cel shading, slightly chunky proportions, friendly and readable at small sizes.
- Mood: hope and everyday humor among ruins. Worn, rusty, patched and repaired, but never gory, scary or dark. No weapons, no blood, no skulls.
- Palette: rust orange, concrete grey, faded olive and teal as the base; warm accents (lamp yellow, fabric red, plant green) for restored and valuable things.
- Lighting: soft warm key light from the upper left, gentle ambient occlusion, no harsh black shadows.
- Objects are original designs for this game. No logos, no brand names, no readable text, no watermarks, no signatures.
- Unless I say otherwise: one centered object, 3/4 front view, fills about 80% of the frame, transparent background, no ground shadow, no frame.
Reply only with the image.
```

## 4. Слоты и размеры

| Категория | Размер | Фон | Что |
| --- | --- | --- | --- |
| `items/` | 256×256 PNG | прозрачный | 22 предмета, ID из каталога; акцент цепочки: T — оранжевые рукояти, M — сталь, P — оливковая упаковка, E — жёлтые провода |
| `generators/` | 256×256 PNG | прозрачный | 4 генератора: крупнее предметов, «мебель», видно, что из них достают |
| `portraits/` | 512×512 PNG | прозрачный | Лев, Ника, Марта по пояс |
| `shop/` | 1200×800 WebP | непрозрачный | `shop_00` — разрушенный магазин, `shop_R01` … `shop_R08` — после каждого ремонта |
| `chests/` | 256×256 PNG | прозрачный | потёртый, торговца, архивный |
| `cards/` | 512×768 WebP | непрозрачный | 9 карт «Старого мира»; рамку редкости рисует игра |
| `ui/` | 128×128 PNG | прозрачный, плитки — непрозрачные | `coin`, `energy`, `token`, `cell`, `cell_locked` |

Где картинка появляется в игре: предметы и генераторы — на поле, складе и в требованиях заказов (номер уровня остаётся маленьким значком в углу); портреты — в диалогах; сцена — сверху экрана «Магазин» (пока нужного шага нет, показывается ближайший готовый более ранний); сундуки и карты — в альбоме (несобранная карта показана тусклой); иконки — в шапке; плитки — фон клеток поля.

## 5. Проверка каждой картинки (обязательно)

Перед коммитом агент смотрит каждую новую картинку:

- PNG с настоящей прозрачностью (кроме магазина, карт и плиток), без белого квадрата;
- размер совпадает со спецификацией;
- объект целиком в кадре, ничего не обрезано;
- нет текста, букв, логотипов, рамок, водяных знаков;
- стиль совпадает с остальной графикой; соседние уровни цепочки различаются силуэтом, а не только оттенком (GAME_DESIGN, раздел 12);
- на листе `items-48px.jpg` предметы различимы;
- сцены магазина: ракурс и расположение зон совпадают на всех шагах, изменение каждого шага видно сразу.

## 6. Подводные камни

- **Эмодзи на Windows 10:** новые значки (Unicode 13+, например 🪙) рисуются пустым квадратом. Для заглушек — только старые эмодзи; монета в шапке поэтому 💰.
- **Генератор дорисовывает фон и землю** — в «Кадре» всегда указано `transparent background, no ground shadow, no backdrop`.
- **«Пустой» объект** генератор наполняет: если нужен пустой ящик или стол, писать прямо `EMPTY`.
- **Правка сцены сдвинула ракурс** — повторить с фразой `Do not change the camera, composition or any other object.`
- **Права:** перед публикацией проверить условия использования изображений ChatGPT для коммерческой игры на эту дату.
