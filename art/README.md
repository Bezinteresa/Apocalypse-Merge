# Графика Apocalypse Merge — начни здесь

Инструкция для того, кто генерирует картинки (человек или ИИ-агент, например ChatGPT с доступом к репозиторию). Работа идёт в ветке `main`.

## Какие файлы что значат

| Файл | Зачем | Кто меняет |
| --- | --- | --- |
| `art/README.md` | Этот порядок работы | — |
| `art/ART_TODO.md` | **Очередь: что сгенерировать сейчас.** Каждая картинка: путь, размер, что нарисовать, правила кадра, что приложить | создаётся скриптом, руками не править |
| `art/generation-prompts.json` | Спецификация всех картинок игры (источник правды для очереди) | только поле `redo`, см. ниже |
| `art/generation-log.json` | Журнал: какая картинка каким промтом сделана | дописывает тот, кто сгенерировал |
| `art/reference/style.png` | Образец стиля — прикладывать к каждой генерации | заменять только по решению пользователя |
| `art/reference/shop_mood.webp` | Образец материалов и света для фона здания | — |
| `art/guides/building_layout.png` | Разметка комнат для фона здания | создаётся `python art/make_layout_guide.py` |
| `public/sprites/<категория>/<файл>` | **Куда кладутся готовые картинки.** Игра подхватывает их сама по имени | скрипт сохранения |
| `docs/ART_PROMPTS.md` | Подробности стиля, сцены магазина и подводные камни | — |

## Порядок работы

1. Обновить очередь:
   ```bash
   node art/art_todo.mjs
   ```
   Открыть `art/ART_TODO.md`. Генерировать **только** то, что там перечислено.

2. Для каждой картинки из очереди собрать запрос: строку «Стиль» из шапки `ART_TODO.md` + «Правила» + «Что» + «Кадр» этой картинки. Приложить `art/reference/style.png` и файл из строки «Приложи как основу», если она есть. Одна картинка — один запрос.

3. Посмотреть результат: нет текста и рамок, фон прозрачный (кроме `shop/` и `cards/`), объект целиком в кадре, стиль как у образца. Неудачное — сгенерировать заново, не сохранять.

4. Сохранить в слот — путь и размер берутся из заголовка картинки в `ART_TODO.md`:
   ```bash
   python art/save_generated_asset.py <скачанный_файл> items/T03.png 256 256 --trim
   ```
   - `--trim` — для отдельных предметов: `items/`, `generators/`, `chests/`, иконок `ui/coin|energy|token`.
   - Без `--trim` — `zones/` (должны заполнять кадр до краёв), `characters/` и `portraits/` (ноги и плечи на месте), `shop/`, `cards/`, плитки и паутина `ui/`.
   - Скрипт не перезапишет готовую картинку; для переделки добавить `--replace`.

5. Дописать запись в `art/generation-log.json` → массив `assets`:
   ```json
   { "file": "items/T03.png", "prompt": "<весь отправленный текст>", "reference": "art/reference/style.png", "generator": "ChatGPT built-in imagegen", "source": "<имя скачанного файла>" }
   ```

6. После партии картинок:
   ```bash
   python art/compress_sprites.py
   python art/verify_generated_assets.py
   node art/art_todo.mjs
   ```
   `verify` не должен показывать ошибок. Посмотреть превью `art/generated-previews/*.jpg`, особенно `items-48px.jpg` — предметы должны различаться в размере клетки телефона.

7. Закоммитить и запушить в `main`: новые файлы `public/sprites/...`, обновлённые `art/ART_TODO.md` и `art/generation-log.json`. Сообщение коммита: `art: <что добавлено>`. Код в `src/` не трогать.

## Что считается готовым

Отдельного списка готовых нет. Картинка готова, когда её файл лежит в `public/sprites/` и имеет размер из спецификации — тогда `art_todo.mjs` убирает её из очереди. Прогресс — строка «Осталось: N» в `ART_TODO.md`.

Если готовая картинка плохая — не удалять, а добавить в её запись в `art/generation-prompts.json` поле `"redo": "что не так"`. Она вернётся в очередь с причиной; новый вариант сохранить с `--replace`, затем убрать поле `redo`.

## Рекомендуемый порядок

1. Предметы — по цепочкам подряд (T01…T06, M01…M05, P01…P05, E01…E06), прикладывая предыдущий уровень: рост должен читаться силуэтом.
2. Генераторы `generators/`.
3. Портреты `portraits/`, затем персонажи в полный рост `characters/` (приложить портрет).
4. Фон здания `shop/building.webp` (приложить разметку и `shop_mood.webp`), затем места ремонта парами: `zones/R0x_broken.png`, потом `zones/R0x_fixed.png` с приложенным `broken`.
5. Сундуки, карты коллекции, иконки и плитки `ui/`.
